# Project 11: Customer Similarity & Insurance Modeling

## Project Description

The Sure Tomorrow insurance company aims to solve several tasks using Machine Learning, and you're asked to evaluate this potential. The tasks include:

1. **Customer Similarity**  
   Find customers who are similar to a given customer. This will help the company's agents with marketing.

2. **Insurance Benefit Eligibility**  
   Predict whether a new customer is likely to receive an insurance benefit. Can a trained prediction model outperform an untrained dummy model? Can it do worse? Explain your reasoning.

3. **Insurance Benefit Quantity**  
   Predict the number of insurance benefits a new customer is likely to receive using a linear regression model.

4. **Data Privacy Protection**  
   Protect clients' personal data without breaking the model from the previous task.  
   This involves building a data transformation algorithm that prevents recovery of personal information if leaked, using techniques such as *data masking* or *data obfuscation*. The transformed data must retain quality so that machine learning model performance is not degraded.
