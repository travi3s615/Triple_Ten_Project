# CV Project	

## Project Description

The supermarket chain **Good Seed** is exploring whether Data Science and Computer Vision can assist in complying with alcohol sale regulations. The goal is to ensure that alcohol is **not sold to underage individuals**. As part of this initiative, your task is to build and evaluate a **model that can determine a person’s age from a photograph**.

This project is centered on training a neural network to estimate age using facial image data. To simulate a real-world environment, the stores are equipped with cameras that activate when a customer attempts to purchase alcohol. The model needs to quickly and accurately estimate the age of a person from a photo to determine whether the sale is allowed.

## Project Instructions

1.  **Pass a quiz** to verify understanding of the project statement.
2.  **Perform exploratory data analysis** to get a better understanding of the dataset.
3.  **Train and evaluate** the neural network model. This must be done using the **GPU platform**.
4.  **Combine code, output, and findings** into a final Jupyter Notebook.
5.  **Make final conclusions** from the model evaluation and add them to the notebook.
6.  **Submit the notebook** for project review.

>  A template Jupyter notebook is provided, which includes **hints** and **precoded cells** to help guide you in training and analyzing your model. Refer to this if you get stuck!

## Data Description

You will receive a dataset containing **photos of people** along with their **actual ages**. Your model will be trained to predict the age using only the images.

Each image in the dataset:
- Is labeled with the true age of the individual.
- Should be preprocessed and normalized for model training.
- Will be used to train a deep learning model (CNN).

The dataset is split into:
- Training and testing subsets.
- Evaluation is done based on predictions made on the test data.
