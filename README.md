# Triple Ten Projects

Projects I worked on while attending the Data Science TripleTen Bootcamp.


| Project number | Title | Description | Feature techniques |
| :-----------: | ----------- |----------- | -------------|
| 1 | Project on IMDb Ratings | The project task was to analyze how the number of votes a show receives impacts its IMDb rating during the “Golden Age” of television. The goal was to test the assumption that highly-rated shows also have the most votes. | Data overview, Data cleaning, EDA |
| 2 | Instacart Project | The project task was to clean up the data and prepare a report that gives insight into the shopping habits of Instacart customers. It involved working with multiple CSVs to analyze grocery order trends, clean missing and duplicate values, and visualize ordering behavior across time, departments, and products. | Data cleaning, EDA, visualization |
| 3 | Statistical Data Analysis | The project task was to carry out a preliminary analysis of the plans based on a relatively small client selection. The data contains 500 Megaline clients: who the clients are, where they're from, which plan they use, and the number of calls they made and text messages they sent in 2018. Analyze clients' behavior and determine which prepaid plan brings in more revenue. | Hypothesis test |
| 4 | Project of Streamlit | The project task was to create and manage Python virtual environments, develop a web application, and deploy it to a cloud service that will make it accessible to the public. | Streamlit, Render |
| 5 | Project of Analyzing Game Data | The project task was to identify patterns that determine whether a game succeeds or not and spot potential big winners and plan advertising campaigns. It included reviewing sales by platform, analyzing user/professional reviews, comparing genres, and testing hypotheses about review score distributions. | Data cleaning and preprocessing, EDA |
| 6 | Project on Analyzing Taxi and Weather Data | The project task was to work with a SQL database and external weather data to analyze ride patterns in Chicago. The goal was to understand passenger preferences and test the hypothesis that weather impacts ride frequency. The project involved writing SQL queries, performing data joins, and conducting statistical testing in Python. | SQL, hypothesis testing, EDA |
| 7 | Project of Machine Learning | The project task was to develop a classification model that recommends the optimal new plan (Smart or Ultra) to legacy subscribers of the Megaline mobile carrier. The model aimed to predict user plan choice based on behavioral features like calls, minutes, messages, and data usage. The goal was to reach an accuracy score of at least 0.75. | Machine Learning Models |
| 8 | Project of Supervised Learning | The project task was to predict whether a customer will leave the bank soon. You were provided with historical customer data, and your goal was to develop a model with the best possible F1 score (at least 0.59), and evaluate it using AUC-ROC. The project included handling class imbalance and comparing model performance. | Machine Learning Models, unbalanced data |
| 9 | Project of Finding the Best Well | The project task was to find the best place for a new oil well. It involved training linear regression models for three different regions to predict reserves, evaluating expected profit, and applying bootstrapping to assess financial risks. The goal was to recommend the region with the highest expected profit and lowest risk. | Machine Learning Models |
| 10 | Gold Recover Prediction | The project task was to predict the amount of gold recovered from gold ore. You were given separate training, test, and full datasets with incomplete and delayed feature availability. The work included checking recovery calculations, identifying missing parameters, analyzing particle size distributions, and evaluating total metal concentrations. You were required to build and validate a predictive model using sMAPE as the evaluation metric. | EDA, Machine Learning Models |
| 11 | Project Related to Linear Algebra | The project task was to help an insurance company explore how Machine Learning could support business goals. Tasks included clustering similar customers, predicting insurance benefit eligibility, estimating number of benefits via linear regression, and anonymizing customer data using transformation techniques. | EDA, Machine Learning Models, KNN classification |
| 12 | Project of Analyzing Models | The project task was to compare different machine learning models in terms of training time and quality of prediction. You were required to train multiple models on the same data, tune hyperparameters, and determine the best model based on accuracy and efficiency. | EDA, Machine Learning Models |
| 13 | Time Series Project | The project task was to predict the amount of taxi orders for the next hour using time series data. You needed to resample historical data by hour, perform exploratory analysis, and train regression models with hyperparameter tuning. The model's RMSE on the test set was required to be under 48. | Time series, Machine Learning Models |
| 14 | NLP Project | The project task was to train a model to automatically detect negative movie reviews. You were provided with an IMDb dataset labeled for sentiment classification. The task involved preprocessing the text, handling class imbalance, training at least three different models, and reaching an F1 score of at least 0.85. You also had the option to explore using BERT for improved performance. | NLP |
| 15 | CV Project | The project task was to evaluate the user's age by the photo. The supermarket chain Good Seed wanted to ensure that alcohol is not sold to underage customers by using computer vision techniques. The task was to build and evaluate a neural network model to predict a person’s age from a photo using a labeled dataset. The project involved exploratory data analysis, training the model (on GPU), and interpreting the model’s performance. | Computer vision |
