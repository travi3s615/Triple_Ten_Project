# Project of Analyzing Models

## Project Description

You're working on a project where you need to evaluate different machine learning models in terms of training time and prediction quality.

Your task is to:

- Train different models with various hyperparameters
- Evaluate their performance
- Identify the best model based on accuracy and efficiency

You’ll be using a dataset that contains information on telecom clients, their features, and whether or not they responded to a promotion.

This project involves experimentation with different models to compare results and analyze which models are best suited to the task, taking into account both performance and computational efficiency.

---

## Project Instructions

1. **Download and prepare the dataset.**
2. **Explore the data:**
   - Check for missing values
   - Analyze distributions
   - Identify categorical features and encode them
3. **Train several models (at least three) with different hyperparameters.**
   - Record training time and prediction time
   - Evaluate models based on quality metrics (accuracy, F1 score, etc.)
4. **Identify the best model by balancing training time and model performance.**
5. **Describe and explain your findings in detail.**

---

## Data Description

The data is stored in a CSV file. Each row contains information about a telecom client.

**Features include:**

- `age` — customer's age
- `gender` — customer's gender
- `income` — income level
- `product_type` — type of product subscribed
- `contract_type` — contract classification (e.g., monthly, annual)
- `churn` — whether the customer left (target variable)
